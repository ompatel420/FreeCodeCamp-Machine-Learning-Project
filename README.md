# Machine Learning with Python – FreeCodeCamp Projects

A collection of five machine learning and artificial intelligence projects developed as part of the **FreeCodeCamp Machine Learning with Python** curriculum.

These projects explore different areas of machine learning, including pattern recognition, computer vision, recommendation systems, regression, and natural language processing.

## 📌 Projects Overview

| No. | Project | Main Technology | Category |
|---|---|---|---|
| 1 | Rock Paper Scissors | Python | AI Strategy & Pattern Recognition |
| 2 | Cat and Dog Image Classifier | TensorFlow, Keras | Computer Vision |
| 3 | Book Recommendation Engine | Scikit-learn, KNN | Recommendation System |
| 4 | Linear Regression Health Costs Calculator | Python, Scikit-learn | Regression |
| 5 | Neural Network SMS Text Classifier | TensorFlow, Keras | Natural Language Processing |

---

## 1. Rock Paper Scissors

**Category:** AI Strategy and Pattern Recognition

### Project Description
A Python-based Rock Paper Scissors game in which an AI player competes against human players and attempts to predict their next moves using patterns from previous rounds.

### Key Features
- Human-versus-computer gameplay.
- Tracks the opponent's previous moves.
- Uses patterns in playing history to predict future moves.
- Implements a strategy to improve the computer's performance.

### Concepts Learned
- Python functions and conditional statements.
- Lists and data structures.
- Pattern recognition.
- Basic AI strategy and prediction.

---

## 2. Cat and Dog Image Classifier

**Category:** Computer Vision and Deep Learning

### Project Description
An image classification project that uses a Convolutional Neural Network (CNN) to distinguish between images of cats and dogs.

The model learns visual patterns from labeled training images and uses those patterns to classify new images.

### Key Features
- Image dataset preprocessing.
- Image resizing and normalization.
- CNN model development.
- Model training and validation.
- Classification of cat and dog images.

### Concepts Learned
- Computer vision.
- Image preprocessing.
- Convolutional Neural Networks.
- Deep learning with TensorFlow and Keras.
- Model evaluation and accuracy improvement.

## 3. Book Recommendation Engine using KNN

**Category:** Recommendation Systems

### Project Description
A book recommendation system that uses the K-Nearest Neighbors (KNN) algorithm to recommend books based on similarities in user ratings and reading preferences.

The system identifies similar books using patterns in the available rating data.

### Key Features
- Loads and processes book rating data.
- Analyzes similarities between books.
- Uses the KNN algorithm.
- Identifies nearby or similar books.
- Recommends books based on similarity.

### Concepts Learned
- Recommendation systems.
- Data preprocessing.
- Similarity measurement.
- K-Nearest Neighbors algorithm.
- Scikit-learn.

---

## 4. Linear Regression Health Costs Calculator

**Category:** Machine Learning Regression

### Project Description
A machine learning project that predicts individual healthcare insurance expenses using personal and demographic information.

The model learns relationships between input features and medical expenses using a Linear Regression algorithm.

### Key Features
- Loads and explores healthcare cost data.
- Preprocesses categorical and numerical features.
- Splits data into training and testing sets.
- Trains a Linear Regression model.
- Predicts healthcare expenses for new records.
- Evaluates prediction performance.

### Concepts Learned
- Linear Regression.
- Exploratory Data Analysis.
- Feature preprocessing.
- Model training and testing.
- Regression evaluation metrics.

---

## 5. Neural Network SMS Text Classifier

**Category:** Natural Language Processing and Deep Learning

### Project Description
An SMS classification system that uses a neural network to identify whether a text message is legitimate (Ham) or unwanted (Spam).

The model processes message text and calculates the probability that a message belongs to the spam category.

### Key Features
- SMS dataset preprocessing.
- Text tokenization.
- Sequence padding.
- Neural network implementation.
- Spam and Ham classification.
- Prediction using a custom `predict_message()` function.

### Concepts Learned
- Natural Language Processing.
- Text preprocessing and tokenization.
- Word embeddings.
- Neural networks.
- Binary classification.
- TensorFlow and Keras.

## 🚀 How to Run the Projects

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open the required Jupyter Notebook in Google Colab or Jupyter Notebook.

4. Install any missing dependencies.

5. Run the notebook cells sequentially.

6. Follow the instructions inside each project to train, evaluate, and test the model.
